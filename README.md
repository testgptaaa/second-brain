# Второй мозг для офисного сотрудника

Десктопный помощник для macOS и Windows, который связывает рабочие документы, страницы, обсуждения и действия в память о задачах. Помогает вспомнить, на чём остановилась работа, найти источник информации и вовремя вернуться к договорённостям.

Статус: согласованы основа архитектуры, файловая память и правила внешнего редактирования; подготовлены ТЗ и план реализации. Приложение ещё не реализовано; команд установки и запуска пока нет. Рабочее название временное.

## Что планируем

- Наблюдение за разрешёнными окнами, доступным текстом интерфейса и открытыми файлами; настройка исключений и полная пауза наблюдения.
- Документы, Word, Excel, Google Docs, Telegram, WhatsApp, Битрикс в браузере; Chrome, Яндекс Браузер, Safari и расширяемая поддержка других браузеров.
- Импорт истории посещений за выбранный период с отличием посещённого адреса от сохранённого содержимого страницы.
- Локальная память в читаемых файлах по датам: заметки и весь сохранённый контекст доступны для просмотра и редактирования сторонними программами; изменения подхватываются, при конфликте сохраняются обе версии. Лента работы, задачи, поиск по словам и смыслу, ответы с источниками.
- Восемь видов подсказок, включая контекст задачи, подготовку к встрече, договорённости, расхождения и итог дня. Отдельные уведомления — только про сроки и встречи.
- Чтение Google Календаря и Apple Notes; новые заметки сохраняются в нашем хранилище. Apple Notes — отдельное подключение для macOS, поддержка на Windows не заявлена.
- Настраиваемое подключение моделей по OpenAI-совместимому API. LM Studio описывается как вариант локальной текстовой модели.

## Обработка данных

Пользователь выбирает анализ изображения моделью или локальное извлечение текста с передачей текстовой модели. Разрешена автоматическая отправка без маскировки, включая персональные данные. Обезличивание текста настраивается отдельно; оно не скрывает данные на приложенной картинке. Журнал показывает режим и содержимое отправок.

Снимки хранятся локально как временные файлы с ручной очисткой и настраиваемыми ограничениями по сроку и размеру. Маскировка изображений и голосовой ввод отложены на самый конец. Создание событий в Google Календаре — дополнительная функция на потом.

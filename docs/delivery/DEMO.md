# Демо M1 через час: подготовка и запись

Цель: видео 4–6 минут с настоящим приложением на Mac и воспроизводимым пользовательским сценарием. Данные синтетические, операции настоящие. Полный исходный продукт M2–M4 этим показом не объявляется готовым.

## Версия и работа Antigravity

Если Antigravity уже меняет проект, сначала посмотреть `git status` и diff, сохранить его изменения отдельным локальным коммитом либо проверенной резервной копией. Не выполнять reset/clean, не перезаписывать файлы из main поверх его работы. Новые demo scripts можно получить после согласованного обновления checkout. За 15 минут до записи прекратить визуальную переделку и зафиксировать версию; исправлять только блокеры выбранного маршрута.

## Визуальные правки

Единые поля/select/фокус/отступы вынесены в `desktop/src/styles/controls.css`, подключение — в `src/main.tsx`. `DateFilter` получил класс `date-filter` для компактной строки фильтров. Не заменять локальный App.css из Antigravity этим файлом: это отдельный слой, его нужно визуально проверить на Mac и согласовать с уже внесёнными стилями. В облаке геометрия/скриншоты не проверены.

## Расписание на 60 минут

| Минуты | Результат |
| --- | --- |
| 0–10 | Приложение запускается на Mac, понятен статус локальных правок; составлен список максимум 3 визуальных блокеров |
| 10–25 | Исправлены обрезанные элементы, наложения, плохой контраст/отступы на маршруте показа; без новой архитектуры/интеграций |
| 25–40 | verify + native smoke, затем ручная репетиция сценария ниже на demo memory |
| 40–45 | Версия зафиксирована, запись экрана/микрофона проверена коротким тестовым клипом |
| 45–55 | Два полных дубля по 4–6 минут |
| 55–60 | Проверить воспроизведение, звук, читаемость и отсутствие случайных личных окон; сохранить финальный файл |

Если установка/запуск занимает больше 10 минут, приоритет — добиться запуска и проверить notes/tasks/search/restart. Второстепенную косметику перенести. Зелёные cloud tests не заменяют эту репетицию на Mac.

## Запуск

Зависимости устанавливаются по README. Из корня проекта:

```bash
bash scripts/verify.sh
cd desktop
npm run test:native
cd ..
bash scripts/demo.sh
```

`demo.sh` создаёт НОВУЮ сессию в ignored `runtime_data/demo-...`, отдельно от личной памяти и Keychain namespace. Запомнить напечатанный абсолютный путь. В ней уже есть 3 заметки, 7 задач, 3 source records и 3 эпизода за разные дни. Все помечены как подготовленные данные. Захват экрана выключен, ключи пустые; вопросы используют явно обозначенный локальный поиск без сетевой зависимости.

Для показа перезапуска закрыть приложение полностью через Cmd+Q и снова запустить **ту же** сессию:

```bash
bash scripts/demo.sh --resume /абсолютный/путь/из/первого/запуска
```

Повторный запуск без `--resume` создаёт другой набор и не доказывает сохранность данных предыдущей сессии.

## Сценарий записи: один рабочий день

| Время видео | Действие | Что проговорить / проверить |
| --- | --- | --- |
| 0:00–0:25 | Открыть dashboard | «Это локальный помощник. Для показа подготовлен тестовый рабочий день; дальше все изменения реально сохраняются». Показать статус подключения и реальные счётчики |
| 0:25–1:10 | Заметки → новая заметка | Название «Результат созвона с Мариной»; текст «Вектор: согласовали бюджет 500 000 рублей. Следующий шаг — отправить смету». Сохранить, выбрать её в списке, изменить «500 000» на «520 000», сохранить |
| 1:10–1:55 | Задачи → новая задача | Название «Отправить смету Вектора», описание «Учесть бюджет 520 000 рублей», срок завтра. Сохранить, открыть редактирование, сменить статус на «В работе» |
| 1:55–2:25 | Фильтры, сортировки и канбан | Показать активные/просроченные, сменить сортировку по сроку/названию, открыть канбан. Не показывать десятки одинаковых переключений |
| 2:25–3:10 | Чат → запрос «Вектор» | Показать явно обозначенный локальный поиск, найденные выдержки и «Открыть…» источник. Проверить, что бюджет 520 000 виден в сохранённом документе. Не называть этот режим ответом внешней модели |
| 3:10–3:40 | История и файлы | Выбрать вчерашний день. В «Файлах» открыть детали подготовленного source record. «Это сохранённые материалы памяти; автоматический импорт и захват экрана — следующий этап» |
| 3:40–4:10 | Настройки → диагностика | Показать состояние ядра и путь журналов. «Ключи на Mac хранятся через Keychain, автоматический сбор в этой версии выключен». Не открывать личные ключи/credentials |
| 4:10–5:00 | Cmd+Q → resume той же сессии | Найти новую заметку с 520 000 и задачу «В работе». Это главная проверка реальной сохранности. Завершить на dashboard/задаче |

Календарь, OCR, системное наблюдение и внешние приложения пока не представлять как рабочие интеграции. Конфликтный сценарий добавлять в видео только после успешной репетиции; в основной пяти минутный маршрут он не обязателен.

```text
Цель: через час записать стабильную 5-минутную демку текущего M1 на Mac.
Сначала сохрани и перечисли свои локальные изменения; не перезаписывай их обновлением из main.
Прочитай docs/delivery/DEMO.md и итоговый M1 report.
Исправь только 3 наиболее заметных визуальных блокера на маршруте:
dashboard → notes CRUD → tasks CRUD/sort → search/source → history/files → diagnostics → restart.
Не добавляй M2, не делай новый редизайн и не подставляй mock вместо backend.
Проверь окно 1440×900 и отсутствие недоступных кнопок на 1024×768.
```

Запись: на Mac `Shift+Cmd+5`, выбрать окно/область приложения и микрофон в параметрах. Сначала сделать 10-секундный клип и прослушать. Затем записать полный сценарий. Проверить финальный файл до отправки. Автоматический native smoke проверяет приложение, но сам по себе не является готовым видеороликом.

# План доведения продукта до готовности

Дата аудита: 2026-10-25. Основная ОС первой приёмки: **macOS** (выбор владельца проекта). Текущая цель: M1. Статус M1: реализация и облачные проверки выполнены; нативная приёмка на macOS ожидается. M1 пока не принят. См. [отчёт реализации](reports/2026-10-25-M1-implementation.md).

## Что считаем концом работы

Ближайшая поставка **M1 — надёжное локальное приложение macOS**: существующие семь вкладок работают с настоящей памятью; задачи и заметки можно создать, прочитать, изменить и удалить; поиск и сортировки воспроизводимы; настройки сохраняются; ошибки видны пользователю и диагностируются по журналу; данные переживают перезапуск. Результат — проверенный локальный запуск из исходников на Mac с инструкцией. Подписанный установщик не является результатом M1.

Это граница ближайшей поставки, а не сокращение исходного ТЗ. Полное завершение основного продукта — M4, включая Windows и обязательные интеграции. Исходные F01–F16 сохраняются. Пока нет протоколов реальных проверок, этапы E01/E02 нельзя считать полностью закрытыми по одному README или зелёным pytest.

## Граница M1

Вкладки: «Сегодня», «Спросить», «Задачи», «Файлы», «История», «Заметки», «Настройки». «Файлы» в M1 — каталог уже сохранённых источников/материалов памяти, их просмотр и переход к связанному контексту. Импорт произвольных PDF/DOCX/XLSX относится к M3; JSON записи источника нельзя выдавать за оригинальный Excel-файл.

«Спросить» без LLM явно показывает локальный поиск и найденные выдержки; не изображает сгенерированный ответ модели. Настроенный LLM имеет корректную обработку ошибок и проверяемый адаптер; реальный сетевой прогон и качество генерации обязательны в M2. На dashboard отсутствующий календарь показывает «не подключён», отсутствующая активность — пустое состояние, а не выдуманные встречи и графики.

Полный захват экрана не входит в M1, но его автоматический запуск до согласия должен быть отключён уже здесь. Ключи не хранятся открытым текстом в SQLite/логах; для локальных секретов используется macOS Keychain с явным состоянием «недоступен». Контроль конфликтов и удалений входит в M1, потому что затрагивает сохранность локальной памяти.

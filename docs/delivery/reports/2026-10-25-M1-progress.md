# M1 — первый проход реализации

Статус: IN_PROGRESS. macOS acceptance не выполнена. База: 6935ec4a351b246160a75e4cc4c0c0328fb921a4, изменения не закоммичены.
Среда: Linux, Python 3.12.14, Node 24.19.0.

## Реализовано

- Стандартные typecheck/verify, версии инструментов и CI workflow (CI удалённо не запускался).
- TLS verification восстановлена во всех httpx clients; маска и отсутствующий ключ при обновлении не заменяют ключ.
- Backend отклоняет capture без persisted consent. Интерфейс выдачи consent ещё не реализован; захват безопасно остаётся выключенным.
- Rebuild удаляет stale index rows; watcher реагирует на удаление.
- Редактирование заметки по ID через API; поддержка вчерашних заметок в storage; UUID новых заметок; list/delete notes/tasks; source listing.
- Task patch сохраняет status при отсутствии поля, допускает очистку срока, защищает task path.
- Вкладки заметок/материалов получают backend данные; заметки create/edit/delete, поиск и две сортировки; задачи — название/срок/delete/cancel и три сортировки.
- Обычный browser mode сообщает об отсутствующем bridge; demo требует VITE_DEMO_MODE=true и имеет индикатор. Фиктивные dashboard данные ещё остаются.
- Bridge ограничивает ожидание, очищает pending при shutdown/error/exit, отклоняет domain conflict.
- Snippet отображается текстом; быстрый prompt переносится в поле чата; история защищена от устаревших ответов.
- Python operational metadata пишется в rotating JSONL, без payload/exception text. Полноценная общая диагностика и обработка сбоя logging ещё не закончены.

## Проверки

- `.venv/bin/pytest core/tests -q`: 18 passed (exit 0), включая 7 новых поведенческих регрессий.
- `cd desktop && npm run verify`: typecheck + renderer build + Electron compile прошли (exit 0).
- Новые тесты проверяют key roundtrip, удаление/rebuild, вчерашнюю заметку, notes CRUD/FTS, task patch, consent gate, path traversal.
- Два первоначальных падения новых тестов были вызваны ожиданием текста без конечного newline: существующий Markdown serializer канонизирует его. Ожидание уточнено до точного канонического результата.
- UI клики, native bridge lifecycle, Keychain, permissions, tray и macOS restart: UNRUN.
